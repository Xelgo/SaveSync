# SaveSync для Windows

SaveSync — утилита для переноса игровых сохранений между компьютерами с Windows 10 и 11. Она отслеживает выбранные EXE и копирует сохранения после выхода из игры, в том числе при запуске через Steam. Google Drive для компьютеров синхронизирует копии между устройствами.

[**Скачать SaveSync.exe**](https://github.com/Xelgo/SaveSync/releases/latest/download/SaveSync.exe) · [Все релизы](https://github.com/Xelgo/SaveSync/releases)

## Настройка

1. Скачайте и запустите `SaveSync.exe`. Установка не требуется.
2. Нажмите **Добавить игру**. Укажите название, полный путь к EXE самой игры и папку сохранений. Для игр из Steam выберите EXE игры в её каталоге установки.
3. Укажите отдельную подпапку игры внутри локальной папки Google Диска, например `D:\Google Drive\Game Saves\Название игры`. Выберите этот же каталог внутри Google Диска на других компьютерах. Локальные пути на компьютерах могут различаться.
4. Оставьте SaveSync запущенным. Кнопка закрытия окна сворачивает его в область уведомлений. Чтобы остановить отслеживание, выберите **Выход** в меню значка SaveSync.

SaveSync работает с обычными локальными папками. Для «Моего диска» в Google Drive для компьютеров используйте режим **Зеркалирование файлов**. [Справка Google](https://support.google.com/drive/answer/13401938?hl=ru)

## Копирование и восстановление

- SaveSync копирует файлы после закрытия всех запущенных экземпляров указанного EXE. Для ручного копирования выберите игру и нажмите **Скопировать на Google Диск**.
- На другом компьютере дождитесь завершения синхронизации в Google Drive, затем выберите игру и нажмите **Забрать с Google Диска** до запуска игры.
- Копирование переносит файлы и подпапки. Совпадающие файлы заменяются, а файлы, которые есть только в папке назначения, сохраняются. Перед восстановлением прежние версии заменяемых файлов сохраняются в `%LOCALAPPDATA%\SaveSync\Backups`. Путь к конкретной копии показан в окне SaveSync.
- Профили хранятся в `%LOCALAPPDATA%\SaveSync\profiles.json`. Настройте их отдельно на каждом компьютере.

## Сборка из исходников

Клонируйте репозиторий и запустите сборку в PowerShell.

```powershell
.\build.ps1
```

Скрипт использует компилятор .NET Framework из Windows. Готовый файл появится в `dist\SaveSync.exe`.
